# 色抽出・変換仕様

## 色データ

抽出結果は、ページに指定された色 `color`、ブラウザが解決した色 `computedColor`、重み `value` を保持する。

- 背景色の重みは表示面積とする。
- 文字色の重みは対象文字数とする。
- 指定色と計算済み色の両方が一致する項目だけを同一色として集計する。

## 可視性

- `display: none`、`visibility: hidden|collapse`、`opacity: 0`の要素とその子孫は集計しない。
- 完全透明な背景は、それ自体を背景色として集計しない。
- 半透明背景は不透明背景と同一視せず、表示上の色を解決するため祖先方向を確認する。
- 背景が見つからない画面領域は白として扱う。

## 色変換

対応入力:

- HEX: 3、4、6、8桁
- RGB/RGBA: カンマ形式とCSS Color 4の空白・スラッシュ形式
- HSL/HSLA
- Lab、LCH
- OKLab、OKLCH
- `color(display-p3 ...)`

変換規則:

- RGBチャンネルは0〜255、アルファ値は0〜1へ収める。
- HEXは不透明なら6桁、透明度があれば8桁で出力する。
- RGB/HSLは不透明なら3チャンネル、透明度があればアルファ値を含める。
- 色相は0以上360未満へ正規化する。
- 広色域からsRGBへの変換で範囲外になる値は、表示可能範囲へ収める。
- 解析できない入力で例外を投げず、呼び出し側が元の値へフォールバックできるようにする。

## 集計

- 指定された表示モードへ変換後、表示、プレビュー、コピー、元の指定色がすべて一致する項目を合算する。
- 合算後は重みの降順とする。
- CSS変数はOriginal表示で指定値を補足表示し、解決後の色を表示・コピーに使用する。

## 要件から導く主要テスト

- `COLOR-001`: HEX、RGB、HSL間の既知の変換例。
- `COLOR-001`: 透明度0、境界値、百分率チャンネルの保持。
- `COLOR-001`: 解析不能入力のフォールバック。
- `COLOR-002`: Lab、LCH、OKLab、OKLCH、Display-P3の代表値。
- `COLOR-002`: 広色域変換値が有効なsRGB範囲に収まること。
- `COLOR-003`: CSS変数の指定値と計算済み色を両方保持すること。
- `EXTRACT-003`: 同じ指定色・計算済み色だけを合算すること。
