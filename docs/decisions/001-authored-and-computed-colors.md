# ADR-001 指定色と計算済み色を両方保持する

- 状態: 採用
- 対象要件: `COLOR-003`, `EXTRACT-003`

## 背景

CSS変数、`currentColor`、広色域カラーなどでは、ページ作者が指定した文字列と、ブラウザが描画に使用する計算済み色が異なる。
どちらか一方だけでは、作者の意図を確認する用途または正確なプレビューのどちらかが失われる。

## 決定

抽出結果では指定色と計算済み色を別々に保持する。
Original表示は指定値を識別可能にしつつ、プレビューと必要なコピー値には計算済み色を利用する。
集計時も両方の組み合わせをキーとし、同じ指定文字列でも解決結果が異なる色を誤って統合しない。

## 影響

- 色変換関数は指定色と計算済み色の両方を入力として受け取る。
- 表示用、プレビュー用、コピー用の値を区別する。
- 色変換と集計をUIから独立した純粋関数としてテストする。
