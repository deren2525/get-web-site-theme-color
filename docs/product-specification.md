# Get Web Site Theme Color プロダクト仕様

この文書は実装方法や画面構造ではなく、ユーザーに提供する振る舞いを定義する。
すべての項目が現在のリリースで完全に実装済みとは限らない。
実装状況はテストとIssueも参照する。

## 色の抽出

### EXTRACT-001 表示中ページの解析

拡張機能はユーザーが明示的にポップアップを開いたとき、現在のタブで表示されているHTTPまたはHTTPSページから背景色と文字色を抽出する。

受け入れ条件:

- 非表示要素の色を集計しない。
- スクリプト、メタデータ、画像、動画など、色面積や文字量を適切に評価できない要素を除外する。
- 透明な背景は、表示上の背景色を祖先要素まで辿って解決する。
- ページから取得した色データを外部サービスへ送信しない。

状態: 一部実装・一部テスト済み

### EXTRACT-002 背景色の重み

背景色は画面上で占める面積を重みとして集計する。
子要素が異なる不透明背景で覆う領域は、親背景の面積から除外する。

状態: 実装済み・統合テスト未整備

### EXTRACT-003 文字色の重み

文字色は表示対象となる文字量を重みとして集計する。
同じ指定色と計算済み色の組み合わせは合算する。

状態: 実装済み・純粋関数のみテスト済み

## 色の表示と変換

### COLOR-001 表示形式

抽出した色をHEX、RGB/RGBA、HSL/HSLA、Originalの各形式で表示・コピーできる。

受け入れ条件:

- アルファ値が1未満の色は、選択形式でも透明度を維持する。
- 同じ表示色へ変換された項目は重みを合算する。
- 変換後の一覧は重みの降順で表示する。
- 解析不能な色は、利用可能な元の文字列または計算済み文字列へ安全にフォールバックする。

状態: 実装済み・テスト追加対象

### COLOR-002 広色域カラー

Lab、LCH、OKLab、OKLCH、Display-P3をsRGB形式へ表示するときは、表示可能範囲へ変換し、変換が発生する可能性をユーザーへ知らせる。

状態: 実装済み・テスト追加対象

### COLOR-003 指定色の保持

Original表示ではCSS変数などページが指定した色表現を保持する。
プレビューとコピーに必要な場合は、ブラウザが解決した計算済み色も保持する。

詳細は [ADR-001](decisions/001-authored-and-computed-colors.md) を参照する。

状態: 実装済み・テスト追加対象

## 操作と失敗

### UI-001 色のコピー

色項目またはグラフを選択すると現在表示している色コードをクリップボードへコピーし、結果を通知する。

状態: 実装済み・UIテスト未整備

### UI-002 解析不能ページ

ブラウザ内部ページ、Chrome Web Store、権限不足、未読み込みのcontent scriptなど、解析できないページでは処理を終了し、ユーザーが次に取れる行動を通知する。

受け入れ条件:

- 再読み込みで復帰できる場合は、通知だけでなく再読み込み操作を表示する。
- Chrome内部ページなど復帰できない場合は、利用できない理由を表示する。

状態: 実装済み・境界テスト未整備

### UI-003 初回案内

初回利用時は色のコピー方法を簡潔に案内し、ユーザーが閉じた後は再表示しない。

状態: 実装済み・E2Eテスト済み

### UI-004 フィードバック導線

ポップアップから問題報告と改善提案を送れる。拡張機能を繰り返し利用したユーザーには、一度だけ率直なレビューを依頼できる。

受け入れ条件:

- レビュー依頼は配色の取得に5回以上成功した場合に限る。
- 特定の評価点を求めず、レビューへの報酬を提供しない。
- ユーザーがレビュー画面を開くか表示停止を選んだ後は再表示しない。

状態: 実装済み・E2Eテスト済み

## テスト方針

- テスト名に関連する要件IDを含める。
- 色の解析、変換、集計は純粋関数の単体テストを中心にする。
- DOM走査とChrome APIは薄い境界へ分け、代表的な統合テストだけを置く。
- UIテストはタブ切り替え、表示形式の選択、コピーなど主要操作を少数確認する。
- CSSクラスやDOM階層のスナップショットを仕様の代わりにしない。
